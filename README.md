# GHOST UA — website

Адаптивний статичний сайт українського GTA RolePlay проєкту.

## Render (Static Site)
- Repository: `EgorMr111/GHOST-UA`
- Branch: `main`
- Build Command: залишити порожнім
- Publish Directory: `.`

## Файли
- `index.html` — структура сайту
- `styles.css` — дизайн і адаптивність
- `script.js` — мобільне меню та рік у футері
- `assets/ghost-ua-hero.png` — головне зображення (додати файл)

Кнопка завантаження навмисно неактивна, доки ZIP-архів клієнта не буде готовий. Коли архів з'явиться, замініть disabled-кнопку на посилання на файл і заповніть версію та розмір.
